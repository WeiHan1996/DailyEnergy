## 打开方式

原型没有依赖和构建步骤。

可以直接在浏览器打开 index.html，也可以从仓库根目录启动任意静态文件服务器，例如：

~~~bash
python3 -m http.server 4173
~~~

然后访问：

~~~text
http://localhost:4173/prototype/s04/
~~~

## 推荐演练顺序

1. 从“新用户首次体验”开始；
2. 完成承接、第一次认识、三项签到、生成、阅读行动和点亮；
3. 点击手机旁的“演示”按钮；
4. 依次检查当日回访、晚间回看、2/5/7 天记录；
5. 检查离线、完整模板降级、个性化缺失和可恢复错误；
6. 检查历史日删除、关系数据删除和 Safety 全屏替代。

“演示场景”面板只用于研究主持和 PR 审核，不是正式产品功能。

## 原型边界

原型只使用静态 HTML、CSS 和少量原生 JavaScript：

- 不发送网络请求；
- 不创建账号或会话；
- 不连接微信、API、模型、数据库或分析平台；
- 不读写 localStorage、Cookie 或其它持久化存储；
- 不调用真实分享、提醒、电话或消息；
- 所有姓名、状态、记录和重要事项均为虚构演示资料；
- 刷新页面会清空原型状态；
- Safety 资源是界面理解占位，仍需后续专业安全规范评审。

## 文件

- index.html：原型外壳、手机容器、演示面板和确认弹层；
- styles.css：移动端布局、内容类型区分、响应式与基础无障碍；
- app.js：仅在内存中运行的演示状态和点击路径；
- README.md：打开、演练和边界说明。
