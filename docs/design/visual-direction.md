## 1. 决策目的

D-001 在不改变 Accepted 产品定位、信息架构、页面结构和状态行为的前提下，比较五条真实可区分的
品牌视觉路线，由项目所有者选定唯一主方向。选定结果将成为 D-002 设计系统和 Design Tokens 的
唯一方向输入。

项目所有者已接受 A — 温柔自然为唯一方向。仓库检查、静态方向板或 Agent 判断仍不能替代 Figma
原始证据和项目所有者决定；本次接受不等同于自动化 PASS。D-001 PR #140 已完成合并。

- 真实状态使用“你的状态/真实记录”，娱乐结果使用“娱乐与行动参考”；
- 低分/低状态不使用警报、破损、枯萎、电量见底或失败隐喻；
- 点亮不依赖任务完成，不做断签损失、积分爆发或强庆典；

- 离线、错误、禁用和 Safety 同时使用文字、结构和图形，颜色不是唯一线索；
- 系统字体放大、读屏、减少动态效果和微信安全区仍是 P0。

## 3. 品牌基线

### 3.1 共同关键词

- 稳定；
- 细心；
- 克制；
- 温暖但不黏腻；
- 清醒但不冷漠；
- 轻盈但不幼态；
- 每天一分钟；
- 真实记录与娱乐参考分层。

### 3.2 共同反关键词

- 神秘权威、转运、命定、恐惧；
- 医疗诊断、心理量表、财务警报；
- 虚拟恋人、真人化在线陪伴、角色商城；
- 粉色女性刻板、撒娇、宝贝/主人等称呼；
- 抽卡、盲盒、宝箱、排行榜、断签火焰；
- 过度庆典、闪烁、持续漂浮、强震动；
- 大面积低对比浅灰与只靠颜色编码。

### 3.3 固定合成内容

五条路线使用完全相同的 DLY-003 Normal/到达行动前内容。字段、文字和数值见
[评审资产说明](./assets/d001/README.md#2-固定比较内容)。路线不得通过改写文案、增删模块或改变分数来制造差异。

## 4. 路线 A — 温柔自然

### 4.1 核心命题

像清晨桌边的一段安静时间：让用户先感到被轻轻接住，再看见一个做得到的方向。自然感来自
有机弧线、留白与光线，不来自“疗愈万物”话术或女性化花卉堆叠。

### 4.2 视觉系统

| 维度     | 方向                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 关键词   | 清晰自然、排版克制、内容清晰、有呼吸感、不甜腻                                      |
| 色彩     | 暖纸 `#F7F4EA`、叶绿 `#3F7C69`、雾绿 `#E4EDE4`、行动浅绿 `#F0F5EB`、墨绿 `#20352E`  |
| 排版     | 系统无衬线通过字重、换行、内容分组和留白建立层级；数字重要但不压过核心提示与行动    |
| 图形     | 右上自然弧线、大圆角内容区与细边框；不叠加其它路线的编辑网格、撞色或材质语法        |
| 插画     | 当前权威代表页不使用插画；后续若需要，只沿用轻量自然日常观察，不增加人物或花卉堆叠  |
| 图标     | 约 1.75px 圆角线性，形状加文字；不使用表情包或填充卡通图标                          |
| 动效     | 一次 180–240ms 轻微舒展；低状态降低幅度，减少动态时直接呈现稳定终态                 |
| 微信实现 | 主要依赖系统字体、纯色、圆角、边框与少量本地矢量；需在 D-002 和真机复核字号与安全区 |

### 4.3 优势与风险

- **优势**：与“温暖、细心”的数字朋友最自然；信息顺序和行动入口清楚；低状态收敛容易；长文阅读舒适。
- **风险**：容易落入同质化疗愈品牌、米色/绿色一体化或“女性就喜欢柔软”的刻板印象。
- **控制**：通过内容分组、字重、边框和留白保证清晰，不用其它路线的色彩或装饰制造差异；自然表达不引入神秘因果。

## 5. 路线 B — 清醒高级

### 5.1 核心命题

像一本每天更新一页的生活编辑册：事实、解释与行动都有明确位置，让稳定与可信成为品牌质感。
高级感来自信息编辑和精确留白，不来自奢侈黑金、超细低对比文字或大面积深色。

### 5.2 视觉系统

| 维度     | 方向                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 关键词   | 清楚、现代编辑感、可信、不冷漠                                                       |
| 色彩     | 纸白 `#F5F6F3`、编辑黑 `#171A1D`、清醒蓝 `#315EE7`、标注黄 `#F2CA52`、灰绿 `#A6B4AD` |
| 排版     | 系统黑体构成清楚字重层级；日期与数字使用等宽特征；中文不追求过细字重                 |
| 图形     | 编辑网格、页码、规则线、开放圆环和裁切视窗；避免数据终端或医疗仪表盘                 |
| 插画     | 编辑式静物裁切、真实日常局部、几何注释；不使用奢侈摄影和黑金神秘质感                 |
| 图标     | 约 1.5px 几何线性，与基线网格对齐；危险/状态操作仍有文字                             |
| 动效     | 120–180ms 行列对齐、定位和轻量进度；减少动态时直接进入终态                           |
| 微信实现 | 系统字体、边框、网格与小面积色块即可实现，五条路线中复杂度最低                       |

### 5.3 优势与风险

- **优势**：信息密度和跨页面一致性最好；真实/娱乐/系统分层最清楚；低状态、错误和 Safety 降噪后仍稳固。
- **风险**：可能被读成效率工具、知识产品或冷淡健康数据面板，削弱朋友感。
- **控制**：保留自然语言、灰绿和标注黄的生活温度；网格只服务阅读，不给用户打分或评判效率。

## 6. 路线 C — 轻快能量

### 6.1 核心命题

像给日常按下一个轻巧的启动键：用节奏、撞色和抽象动作轨迹增强每天见面的期待，但不把体验变成
抽卡、打卡或任务游戏。

### 6.2 视觉系统

| 维度     | 方向                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 关键词   | 有劲、轻松、模块节奏、不幼态                                                         |
| 色彩     | 亮纸 `#F7F7F2`、清亮青 `#146E6B`、活力橘 `#F26B4F`、日光黄 `#F5CC45`、深墨 `#282832` |
| 排版     | 圆润系统黑体配紧凑数字；通过字号、色块和节奏分组产生趣味，不用表情包                 |
| 图形     | 节拍线、日光、动作路径与小面积几何撞色；不画卡牌、宝箱、宠物或火焰                   |
| 插画     | 抽象动作轨迹、通勤和桌面小物的简化组合；避免潮玩 IP 和幼态拟人                       |
| 图标     | 约 2px 圆角几何；图标与明确动作文字并用                                              |
| 动效     | 一次 140–220ms 节拍推进；低状态降速减色，减少动态时静态分步                          |
| 微信实现 | 小面积色块和简单 transform 可实现；必须控制同时出现的颜色和动效数量                  |

### 6.3 优势与风险

- **优势**：渠道首图和第一天吸引力最强；点亮反馈与行动节奏有辨识度；更能承载人格中的轻盈与幽默。
- **风险**：容易被误读为习惯打卡、效率挑战或抽卡游戏；低状态下撞色可能显得不体贴。
- **控制**：低状态、错误和晚间页面进入减色模式；点亮只做一次克制反馈；不出现积分、连续天数损失或奖励容器。

## 7. 路线 D — 都市柔光

### 7.1 核心命题

像下班后仍然清醒的一束室内光：面向 22–35 岁职场女性的真实生活感，自持、细腻、有质感，但不把
“女性审美”简化成粉色、甜美、美妆、恋爱或幼态装饰。表达女性用户是完整、自主且有判断力的人。

### 7.2 视觉系统

| 维度     | 方向                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 关键词   | 自持、细腻质感、都市日常、不迎合                                                 |
| 色彩     | 清纸 `#FBFAF8`、梅子 `#7B355B`、冷丁香 `#C7B8D5`、青瓷 `#78998D`、深墨 `#2B2830` |
| 排版     | 重点判断与主要行动使用现代宋体回退；分数降为行内辅助信息，正文用系统黑体保证阅读 |
| 图形     | 室内柔光切面、织物层次、开放圆环和精细规则线；不使用蝴蝶结、爱心或身体轮廓       |
| 插画     | 通勤、阅读、桌面、器物和城市生活的局部观察；不默认美妆、恋爱或精致消费场景       |
| 图标     | 约 1.5px 精细圆角线性，图标与文字并用                                            |
| 动效     | 一次 180–240ms 光面转移或层级聚焦；低状态降低明度，不把用户画成脆弱或需要拯救    |
| 微信实现 | 基础色面、边框和本地矢量可实现；宋体回退与阴影性能需 D-002/真机复核              |

### 7.3 优势与风险

- **优势**：对种子用户的生活语境最直接；兼顾朋友感与成熟审美；内容与渠道视觉均有辨识度。
- **风险**：可能被读成生活方式杂志、精致消费或另一种“为女性设计”的表面包装。
- **控制**：所有视觉都服务事实、解释和行动；日常参照保持多元、可负担、非消费导向；拒绝性别刻板符号。
- **当前层级约束**：`360 x 844` 手机视口内完整展示从问候到点亮条件；数值只提供快速背景，不得压过
  今日重点与行动；层级优先通过内容浓缩、分组、颜色和留白建立，不依靠单纯放大字号。“今天可以
  这样做”使用梅子色宋体层级，青瓷行动区和行动句是页面主角。

## 8. 路线 E — 克制空间

### 8.1 核心命题

提炼苹果式设计中有价值的原则：充足留白、系统字体、清晰层级、精确间距、轻材质和克制动效，让
每天一分钟的内容像系统能力一样自然。保持 DailyEnergy 原创，不复制苹果 Logo、产品截图、专有资产、
组件外观或整体 Trade Dress。

### 8.2 视觉系统

| 维度     | 方向                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| 关键词   | 空间感、精确、轻材质、原创克制                                                            |
| 色彩     | 雾银 `#F8F9FB`、纯白 `#FFFFFF`、石墨 `#17191C`、钛灰 `#7D8793`、聚焦蓝 `#1768E5`          |
| 排版     | 只使用系统无衬线字体，以字号、字重和空间建立层级；中文不使用不稳定的超细字重              |
| 图形     | 大留白、少量悬浮面、精确圆环和一个受控强调色；不复刻平台图标、硬件轮廓或苹果营销构图      |
| 插画     | 原创光影、材质与日常物件微距；不使用苹果产品图、壁纸或发布会式视觉                        |
| 图标     | 约 1.5px 系统线性，熟悉操作优先使用平台惯例，非通用含义必须有文字                         |
| 动效     | 160–220ms 层级淡入和短距离位移；减少动态时直接显示稳定终态                                |
| 微信实现 | 主要结构容易实现；阴影、透明度和潜在模糊效果必须在低端 Android/微信真机验证并提供纯色降级 |

### 8.3 优势与风险

- **优势**：信息层级清楚、跨端一致性强、学习成本低；克制感适合每天高频打开。
- **风险**：容易变成无品牌性的系统工具，或因表面相似而被误读为模仿苹果。
- **控制**：保留 DailyEnergy 自己的文案、能量语义和原创图形；严格记录素材来源，不使用苹果专有资产。

| 最强人格特质   | 温暖、细心           | 清醒、克制             | 轻盈、偶尔幽默     | 平等、细腻、自持     | 清楚、稳定、不过度打扰 |

项目所有者选择时应回答：哪一种第一感知最接近 DailyEnergy 想长期拥有的品牌资产？选择只锁定主方向，
D-002 仍需把颜色、排版、间距、组件、动效和无障碍转换为可执行 Tokens 与组件规则。

Figma 建立后，五条路线在最终选择前都可继续调整；选定主方向后，仍可在该方向内调整颜色、排版、
图形、动效和语气。若之后改选另一条主方向，必须更新下方选择记录、影响说明和用户确认，不能让
