# DailyEnergy 交互状态与恢复规则

- **文档状态**：Draft
- **所属任务**：S-03 — 交互状态与页面规格
- **最后更新**：2026-07-20
- **适用范围**：微信小程序、系统弹层、最小管理后台的用户可见状态
- **上游文档**：[页面清单](./screen-inventory.md)、[页面规格](./screen-specs.md)
- **配套文档**：[内容布局](./content-layout.md)

## 1. 文档目的

本文定义 DailyEnergy 在首次、返回、重复提交、加载、离线、降级、跨日、删除和安全情形下如何选择状态、展示反馈并恢复。

本文是交互状态规格，不替代后续产品状态机、稳定种子、API 错误码、数据保留和安全响应规范。后续文档可以给状态增加机器字段，但用户可见行为不得与本文冲突，除非先重新审核 S-03。

## 2. 状态设计目标

- 用户始终知道系统是在读取、提交、生成、等待恢复还是已完成；
- 同一意图重复发生时只产生一个逻辑结果；
- 可恢复问题留在原任务附近，不把局部失败升级成全站故障；
- 已缓存、已确认的内容优先可读；
- 没有数据就显示缺失，不通过 AI 推断或视觉连线补齐；
- 安全、隐私和数据权利高于流程连续性和娱乐体验；
- 技术细节只进入日志和后台，不进入用户文案；
- 动画、颜色和触感只辅助状态，不能成为唯一提示。

## 3. 状态优先级

当多个状态同时存在时，按以下优先级决定页面：

| 优先级 | 状态 | 行为 |
|---:|---|---|
| 1 | Safety 高风险替代 | 进入 SAFE-001，抑制普通内容和导航 |
| 2 | Deleting 关系数据/注销 | 进入 SET-006 或 SYS-003 删除处理中 |
| 3 | 账户阻断/维护 | 进入 SYS-003；不可绕过 |
| 4 | 会话恢复 | 静默恢复，失败进入 ENT-002 |
| 5 | 产品日期与深链资格 | 确定目标日期和合法落点 |
| 6 | 今日结果状态 | 未签到、提交中、生成中、已生成或硬失败 |
| 7 | 页面内容状态 | Loading、Empty、Fallback、局部错误、Completed |
| 8 | 非核心权限与模块 | 通知、分享、提醒、局部卡片可单独禁用 |

规则：

- 高优先级状态不得被低优先级缓存覆盖；
- 安全响应加载地区资源失败时仍留在安全页；
- 删除处理中不能因为今日缓存存在而回到 DLY-003；
- 普通模块失败不应覆盖已可读的今日内容；
- 深链只能在高优先级检查通过后生效。

## 4. 通用状态词典

| 状态 | 用户可见表现 | 可做 | 不可做 |
|---|---|---|---|
| Normal | 完整内容与当前主操作 | 正常浏览和提交 | 无 |
| Loading | 对应区域骨架、按钮忙碌态、读屏状态 | 取消允许取消的读取；浏览已稳定内容 | 重复提交 |
| Empty | 解释为什么没有内容及下一步 | 回今日、开始新增 | 伪造示例为真实数据 |
| Recoverable Error | 原位简短说明、重试、稍后 | 保留输入并重试同一意图 | 清空数据、创建新意图 |
| Offline | 明确离线与缓存时间 | 阅读允许的缓存、退出 | 生成、写入、删除、导出、授权变更 |
| Fallback | 结构完整时正常展示；明显少个性化时轻提示 | 完成阅读、行动和点亮 | 查看技术原因、重新抽取 |
| Disabled | 保留控件并说明条件 | 完成其他功能 | 通过反复点击绕过条件 |
| Completed | 显示结果、时间或幂等完成状态 | 查看、允许时修改 | 重复创建同一记录 |
| Safety | 全屏固定响应 | 获取现实帮助和审核资源 | 普通运势、任务、点亮、分享 |
| Deleting | 处理范围、状态和支持 | 查看进度、退出 | 重复发起、访问承诺删除的数据 |

## 5. 启动与会话恢复

### 5.1 启动顺序

1. 读取本地最小路由快照，仅用于立即骨架和候选落点；
2. 检查安全、账户、删除与维护状态；
3. 恢复或建立会话；
4. 确定产品日期；
5. 校验深链；
6. 读取今日结果状态；
7. 进入业务页面；
8. 后台刷新非关键模块。

本地快照不能直接证明安全状态已解除、删除已完成或今日可重新生成。

### 5.2 等待反馈

- 0～约 400 毫秒：可保持启动静态画面，避免骨架闪烁；
- 超过短等待：显示最小骨架；
- 超过约 3 秒：出现可理解短句和“重试/稍后”条件；
- 不显示不真实的百分比、队列名或供应商状态；
- 动效开启减少动态效果时改为静态状态符号和文本。

这些阈值是原型建议，性能规范可在不改变心智模型的前提下调整。

### 5.3 会话失败

- 首次临时失败：静默有限重试；
- 仍失败：ENT-002 显示“重新连接”；
- 网络离线：不循环拉起微信授权；
- 用户取消系统身份流程：回 ENT-002，允许稍后；
- 成功恢复：按服务端真相重新路由，不重复认识或签到。

## 6. 首次流程与草稿

| 步骤 | 草稿规则 | 退出后恢复 | 提交规则 |
|---|---|---|---|
| ENT-001 必要同意 | 只有明确同意后保存 | 未同意回承接 | 同意请求幂等 |
| ONB-001 称呼/风格 | 已输入但未提交仅作本地短期草稿 | 同产品日期可恢复；用户可清空 | 服务端只保存最终提交 |
| DLY-001 三项签到 | 未提交选择仅作本地草稿 | 当日可恢复；跨日必须重新选择 | 提交后冻结为当日输入 |
| DLY-002 生成 | 无新的用户草稿 | 恢复同一任务 | 不能创建第二任务 |

隐私要求：

- 本地草稿只保留完成当前步骤所需的最少内容；
- 自由文本不因崩溃恢复需求而无限期保存；
- 注销、删除或退出关系数据后清除对应草稿；
- 跨日期时签到草稿失效，并用自然文案重新询问今天状态。

## 7. 签到提交、生成与幂等恢复

### 7.1 提交前

- 三项选择可修改；
- 未完成项在提交时就地提示；
- “说不准”是有效选择，不是错误；
- 返回不会产生正式签到或今日结果。

### 7.2 提交中

- 第一次点击后立即进入忙碌态；
- 选择控件锁定，主按钮显示“正在保存”；
- 连续点击、双击和系统重试复用同一逻辑意图；
- 客户端超时不代表提交失败，必须先查询已有状态；
- 只有确认没有有效提交时才允许同一意图重试。

### 7.3 生成中

生成只存在一个逻辑任务：

- 已有当天结果：直接读取；
- 任务进行中：订阅/轮询同一任务；
- 规则结果已完成、表达未完成：继续受控表达或模板；
- AI 超时/校验/审核失败：切换受控模板；
- 模板成功：保存唯一当天结果并进入 DLY-003；
- 无法生成安全完整结果：进入 Recoverable Error，最终才进入 SYS-003。

### 7.4 未知结果恢复

当用户点击后断网或应用退出：

1. 保留“请求可能已提交”的本地标记；
2. 恢复网络后先读取当天正式状态；
3. 若结果存在，进入 DLY-003；
4. 若任务进行中，进入同一 DLY-002；
5. 若明确未创建，才重新提交相同选择；
6. 不向用户提供“再生成一份”。

### 7.5 已生成后修改

- 称呼或风格修改：对后续允许变化的表达生效；当天核心结果不变；
- 当天签到发现误选：可以在后续数据规则明确后允许更正真实记录，但不重算当天核心结果；
- 算法、Prompt 或模型升级：不改写历史结果；
- 当天重复进入：恢复同一内容、点亮、任务和反馈。

## 8. 页面加载与局部失败

### 8.1 骨架原则

- 骨架形状与最终内容大致一致，避免大幅跳动；
- 不用随机假文案模拟真实内容；
- 已稳定内容不因刷新变回全屏骨架；
- 图表骨架不能伪造走势；
- 读屏说明“正在加载某区域”，完成后更新状态。

### 8.2 局部优先

| 失败模块 | 保留内容 | 局部处理 |
|---|---|---|
| 五维展开失败 | 整体能量、解释、行动、点亮 | 展开区重试 |
| 帮助度提交失败 | 今日内容和其他操作 | 保留选择，原位重试 |
| 晚间卡片失败 | 今日内容 | 隐藏卡片或显示稍后重试 |
| 趋势总结失败 | 真实图表和日记录 | 总结区使用基础说明 |
| 分享卡生成失败 | 今日核心体验 | 预览区重试，不影响返回 |
| FAQ/支持失败 | 设置目录 | 对应模块重试 |

只有关键账户状态、唯一今日结果无法读取且不能安全降级、或删除导致不可用时进入 SYS-003。

### 8.3 错误文案结构

用户文案只包括：

1. 发生了什么层级的影响；
2. 已保存的内容是否还在；
3. 可以做什么；
4. 需要支持时的参考号。

不包括错误堆栈、数据库名、模型名、Prompt、Token、供应商或内部策略。

## 9. 离线与缓存

### 9.1 离线可读

在设备已有有效缓存且没有更高优先级阻断时，可读：

- 当天已生成的 DLY-003 内容快照；
- 当天点亮、任务和反馈的最后同步状态；
- REC-001 最近 7 天真实记录快照；
- REC-002 已缓存历史日；
- MEM-001、SET-001、SET-002、SET-004、SET-005 的最后同步内容和静态说明；
- ENT-001 的静态产品介绍。

必须显示“离线内容”及最后同步时间，避免把缓存当成最新状态。

### 9.2 离线禁用

- 新用户必要同意与会话建立；
- 提交签到和生成今日结果；
- 点亮、任务状态、帮助度和晚间反馈写入；
- 新增/编辑/删除重要事项；
- 修改资料、提醒和授权；
- 生成分享卡或调用需要在线的分享能力；
- 数据导出、单日删除、关系数据删除和注销；
- 解除 Safety、Deleting 或账户阻断状态。

MVP 不做离线写队列，避免冲突和用户误认为已保存。恢复网络后用户主动重试同一操作。

### 9.3 缓存失效

以下情况不能继续展示敏感缓存：

- 用户明确注销或删除关系数据；
- 账户切换；
- 缓存完整性校验失败；
- 服务端标记安全或账户阻断；
- 数据保存政策要求失效。

产品日期变化不会自动删除历史缓存，但当天入口必须重新校验。

## 10. 降级层级

| 层级 | 条件 | 用户表现 |
|---|---|---|
| F0 正常 | 规则和个性化表达完整 | 正常今日内容 |
| F1 模型切换 | 备用表达保持同等结构和个性化 | 不提示技术变化 |
| F2 完整模板 | 结构化事实、人格和风格仍完整 | 正常完成，不提示“AI 故障” |
| F3 个性化减少 | 记忆或偏好暂时不可用，但内容安全完整 | CMP-009 一条中性说明 |
| F4 硬失败 | 无法得到结构完整、安全、稳定内容 | 原位重试；最终 SYS-003 |

共同规则：

- 所有降级仍保持当天结果稳定；
- 降级不能改变规则分数或制造新事实；
- F3 提示不要求用户重新提供敏感信息；
- 恢复服务后不静默替换当天已经展示的结果；
- 后台记录真实降级原因和版本，用户端不暴露技术细节。

## 11. 权限拒绝与系统能力

| 权限/能力 | 拒绝后的行为 | 恢复入口 |
|---|---|---|
| 微信会话必要能力 | 无法开始业务，进入 ENT-002 | 重新连接 |
| 订阅消息 | 只关闭提醒 | SET-003 |
| 分享 | 保留预览或说明不可用，不影响今日 | SHR-001 或系统设置 |
| 重要事项提醒 | 可保存事项，但提醒开关禁用 | MEM-002 / SET-003 |
| 支持附件等未来能力 | 只影响该反馈附件 | SET-005 |

规则：

- 不在用户拒绝后立刻循环请求；
- 说明用途和替代路径；
- 权限状态变化后重新读取，不假设已授权；
- 平台永久拒绝时提供系统设置方向，但不阻塞无关功能；
- 最终微信能力需在实现前复核，复核不能降低上述用户边界。

## 12. 数据不足与空状态

### 12.1 七天记录

- 0 天：Empty，“从今天开始”，无图表走势；
- 1～2 天：显示离散记录点和样本数，不使用“上升/下降/稳定”等趋势词；
- 3～6 天：允许基础方向描述，但必须写“基于 N 天记录”，缺失日期不连线；
- 7 天：可展示完整七天回望；若字段仍缺失，逐项标注；
- AI 总结失败：保留真实数据，用固定说明替代；
- 删除后样本数回退并重新应用同一规则。

### 12.2 历史日

- 有今日能量、无晚间反馈：明确“这天没有留下晚间记录”；
- 只有部分真实字段：逐项缺失，不用其它字段推断；
- 整日删除：列表可保留缺失日期占位，详情不再展示已删除内容；
- 没有缓存且离线：说明需联网读取，不展示虚构示例。

### 12.3 重要事项和后台

- MEM-001 无事项：说明可选及新增入口；
- ADM 页面无结果：显示筛选范围和“没有数据”，不能默认解释为健康；
- 权限导致空：明确“无权查看”，不要伪装成无事件。

## 13. 晚间反馈状态

### 13.1 出现时机

- 18:00 后：DLY-003 末端出现 CMP-006；
- 18:00 前：不抢占今日主操作，可从次级“现在回看”主动进入；
- 当天首次生成发生在晚上：先完成今日阅读，反馈入口置于内容末端，不强制弹出；
- 次日：MVP 不强迫补填昨日；历史详情只显示缺失；
- 确切时区算法由后续产品日期 ADR 固化。

### 13.2 编辑与冲突

- 同一天反馈可修改；
- 提交中重复点击复用同一反馈意图；
- 多端或重复页面冲突时先读取最新版本，再提示用户是否应用当前修改；
- 产品日期结束后的可编辑窗口由业务规则文档决定；本任务不承诺无限编辑；
- 安全分类命中时停止普通保存收尾并进入 SAFE-001。

## 14. 跨日期

### 14.1 正在阅读时跨日

- 不突然替换当前 DLY-003；
- 页面顶部显示“新的一天已经开始”轻提示；
- 用户完成当前只读操作或主动点击后，进入 SYS-001 重新路由；
- 对旧日的写操作按后续业务规则判断；没有明确规则时禁用并解释，不能错误归到新日。

### 14.2 生成中跨日

- 已在旧产品日期创建的生成任务仍归旧日；
- 恢复时先说明日期并读取唯一旧日结果；
- 不自动把旧日签到复制成新日签到；
- 如果旧日结果不再允许继续，回今日入口并清楚说明，不重算到新日。

### 14.3 晚间深链跨日

- 深链携带的目标日期必须校验；
- 过期时不强迫补填，进入当前今日页或历史详情；
- 消息中不包含敏感状态或坏运势紧迫感。

## 15. 删除、导出与注销

### 15.1 单日或单事项删除

1. 用户从 REC-002 或 MEM-002 发起；
2. SYS-002 明确列出对象、不可逆性和影响；
3. 一次确认后进入提交中；
4. 请求幂等；
5. 成功后刷新来源列表/趋势；
6. 失败保留原数据和重试；
7. 不使用第二次情绪化挽留。

单日删除必须说明趋势样本数和总结会重新计算或失效。删除后缺失日期如实存在。

### 15.2 导出

- 发起前说明范围、交付方式和预计处理方式；
- 重复点击复用已有导出任务；
- Deleting 状态不与导出状态混淆；
- 失败可重试，不影响日常使用；
- 具体文件格式和保存期限由后续隐私规范决定。

### 15.3 关系数据删除或注销

1. SET-004 选择操作；
2. SET-006 专页说明范围和例外；
3. 需要时重新验证身份；
4. 最终明确确认；
5. 创建唯一处理任务；
6. Deleting 期间阻止访问承诺删除的数据；
7. Completed 后清除本地缓存与会话并回到结束状态；
8. 失败时说明仍保留的范围并提供支持。

不得用连续天数、数字朋友情绪、优惠或“关系会受伤”阻止删除。

## 16. Safety 全屏替代

### 16.1 进入

任意可检查的用户输入命中高风险时：

- 当前普通提交不继续生成娱乐内容；
- 页面直接替换为 SAFE-001；
- 已在屏幕上的普通内容不继续暴露；
- 最小安全事件与响应版本受限记录；
- 资源加载与普通 AI 链路分离。

### 16.2 页面约束

- 无今日页顶部导航、返回记录、点亮、任务、帮助度、分享或幸运元素；
- 主操作指向现实帮助；
- 系统返回不能显示刚才被替代的普通页面；
- 用户仍可以退出小程序或使用系统级安全操作；
- 网络失败时保留通用、审核过的紧急求助说明；
- 不通过开放式 AI 生成安全长文。

### 16.3 恢复

- 重启应用仍先检查 Safety 状态；
- 普通旅程恢复条件由后续安全规范定义，不能由前端倒计时自行解除；
- 恢复后也不补发当时被停止的娱乐内容；
- 管理后台不能随意篡改用户内容以解除安全状态；
- 地区资源、热线和文案必须经过专业评审并版本化。

## 17. 管理后台状态

- 登录和权限失败优先于所有业务页面；
- 指标卡失败局部展示，不把无数据当 0；
- 生成详情只显示脱敏链路，敏感字段默认不可见；
- 版本发布、回滚、数据请求和安全处理使用确认、权限和审计；
- 列表 Loading、Empty、Error、Disabled 明确区分；
- 删除任务 Deleting 不能通过刷新重复创建；
- 安全事件页加载失败不应在普通指标页泄露替代数据；
- 时间、环境、版本和样本量始终可见。

## 18. 防重复验收表

| 操作 | 重复触发的正确结果 |
|---|---|
| 必要同意 | 同一同意状态，不重复创建用户 |
| 完成认识 | 更新同一资料，不产生多份关系 |
| 提交签到 | 同产品日期一份有效签到意图 |
| 生成今日 | 一份有效结果，刷新不改变 |
| 点亮 | 一条点亮记录，视觉反馈最多一次 |
| 标记任务 | 更新同一任务状态 |
| 晚间反馈 | 创建或更新同一日反馈 |
| 帮助度 | 更新同一结果反馈 |
| 保存重要事项 | 一次保存意图；重试不复制 |
| 删除 | 一个删除任务 |
| 导出 | 复用进行中的导出任务 |
| 注销 | 一个注销任务 |
| 分享卡 | 可重复预览，但不把生成计作实际分享 |

## 19. 原型验收场景

原型至少演练：

1. 新用户正常完成第一天；
2. ONB-001 退出后恢复；
3. DLY-001 双击提交；
4. DLY-002 等待、退出与返回；
5. 模型失败但模板成功；
6. 个性化缺失提示；

12. 通知和分享权限拒绝；
13. 零点跨日；
14. 注销 Deleting 与完成；
15. 高风险替代、资源加载失败和受控返回。
