## 1. 用途

本目录承载 D-001 的仓库内可复核视觉证据。`index.html` 使用同一组固定合成内容和同一张
DLY-003 概念页比较五条方向：

- A — 温柔自然；
- B — 清醒高级；
- C — 轻快能量；
- D — 都市柔光；
- E — 克制空间。

评审页不连接账号、API、分析平台或第三方资源，不写入任何数据。可以直接在浏览器打开；
若浏览器限制本地文件样式，也可从仓库根目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/docs/design/assets/d001/
```
