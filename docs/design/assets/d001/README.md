## 1. 用途

本目录承载 D-001 的仓库内可复核视觉证据。项目所有者已接受 A — 温柔自然为唯一方向；
`index.html` 仍保留同一组固定合成内容和同一张 DLY-003 概念页的五条历史对比：

- A — 温柔自然；
- B — 清醒高级；
- C — 轻快能量；
- D — 都市柔光；
- E — 克制空间。

A 的权威视觉以 Figma `01B / Gentle Nature / DLY-003`（Frame `1:119`）及
[项目所有者提供的导出截图](./evidence/a-figma-authoritative.png)为准。本地 A 概念页只向该截图同步，
不吸收 B、C、D、E 的视觉元素；其它路线保留为 D-001 选择过程证据，不再是下游设计输入。

评审页不连接账号、API、分析平台或第三方资源，不写入任何数据。可以直接在浏览器打开；
若浏览器限制本地文件样式，也可从仓库根目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/docs/design/assets/d001/
```
