## 1. 文档目的

本文定义 DailyEnergy 第一阶段的信息架构、页面层级、入口、导航、主要流程和系统状态归属。

它回答：

- 用户从小红书或抖音进入后落在哪里；
- 新用户和返回用户分别看到什么；
- 每日签到、今日内容、点亮、晚间反馈和七天趋势如何连接；
- 设置、记忆、隐私和删除从哪里进入；
- 加载、失败、降级和高风险状态由哪个页面承接；
- 小程序与最小管理后台如何分工；
- MVP 是否需要首页、TabBar、日历和独立角色页面。

本文不定义最终视觉、字段类型、数据库、API、Prompt 或实现代码。

## 2. 核心架构结论

本稿提出以下推荐方案，等待 PR 审核后生效：

1. **不设置独立功能首页**：小程序根页面就是动态“今天”入口。
2. **MVP 不使用底部 TabBar**：核心任务单一，记录和设置从今天页进入。
3. **首次认识只使用一个主要页面**：称呼与表达偏好在同一页面完成。
4. **五维状态在今日内容页渐进展示**：先看整体和今日重点，再展开其余维度。
5. **晚间反馈从今日内容页进入**：到合适时段出现入口，也支持订阅消息深链。
6. **记录页只做最近 7 天趋势和近期日记录**：MVP 不提供完整月历和月度趋势。
7. **重要事项有独立列表与编辑页**：第 4 天从今天页出现可跳过邀请，长期入口位于设置。
8. **设置与隐私分层**：设置是入口，隐私与数据管理是独立页面。
9. **分享入口位于今日内容和七天总结**：分享前必须进入预览。
10. **自动模板降级不展示技术错误**：只有个性化明显不可用或服务硬失败时才给非技术说明。

这些结论优先服务“一分钟、一个朋友、一个今日行动”的克制体验。

## 3. 信息架构原则

### 3.1 今天优先

用户打开产品的首要目的不是浏览功能，而是完成今天的一分钟。

根页面应根据状态直接路由到：

- 第一次认识；
- 今日签到；
- 正在生成；
- 已生成的今日内容；
- 可用的晚间反馈；
- 必要的安全或错误状态。

### 3.2 渐进披露

首次只收集：

- 称呼；
- 表达偏好；
- 今日情绪、精力和睡眠。

生日、作息、提醒、重要事项和其他资料在用户获得价值后再邀请，不阻塞第一次点亮。

### 3.3 一个页面一个主目标

- 认识页：完成最小关系设置；
- 签到页：表达当前状态；
- 今日页：看见重点并选择一个行动；
- 晚间页：留下真实反馈；
- 记录页：看见最近变化；
- 重要事项页：管理主动记忆；
- 设置页：管理偏好、权限和数据。

### 3.4 正常与异常使用同一心智模型

网络重试、模板降级和重复进入不应把用户带到陌生的“系统后台”体验。

异常状态尽量嵌入当前页面；只有无法继续、安全响应、数据删除和维护状态使用独立页面。

### 3.5 娱乐与真实分层

今日能量属于娱乐和行动参考；签到、晚间反馈和趋势属于真实记录。

页面在标题、颜色、标签和说明上必须区分，不能把今日能量曲线伪装成用户真实状态变化。

## 4. 系统边界

### 4.1 微信小程序

负责：

- 渠道承接；
- 身份与最小授权；
- 首次认识；
- 每日签到；
- 今日内容和点亮；
- 晚间反馈；
- 七天趋势与历史日详情；
- 结构化记忆和重要事项；
- 分享与提醒；
- 偏好、隐私和数据权利；
- 安全与错误状态。

### 4.2 业务服务

不作为可见页面，但在信息架构中必须有明确系统状态：

- 用户和会话；
- 产品日期；
- 稳定种子与规则结果；
- AI 生成与本地模板降级；
- 幂等、缓存和队列；
- 内容安全；
- 记忆过滤；
- 趋势和总结；
- 分享卡片；
- 通知；
- 数据导出和删除；
- 埋点和审计。

### 4.3 最小管理后台

负责：

- 生成健康状态；
- Prompt、模型、规则和模板版本；
- 内容反馈；
- 脱敏安全事件；
- 用户支持和数据请求；
- 关键指标与成本；
- 受控发布和回滚。

管理后台不直接编辑用户的日常情绪或伪造记录。

## 6. 启动路由

### 6.1 启动路由不是可见首页

启动路由负责读取最小状态并决定目标页。它可以使用启动屏或骨架反馈，但不能让用户手动选择“我要去哪”。

路由输入至少包括：

- 会话是否有效；
- 是否完成首次认识；
- 当前产品日期；
- 当天签到是否存在；
- 当天结果状态；
- 当天是否点亮；
- 晚间反馈是否可用或已完成；
- 是否来自指定深链；
- 是否存在必须优先处理的安全或账户状态。

### 6.2 默认路由表

| 条件 | 目标 |
|---|---|
| 首次访问或未同意必要说明 | ENT-001 承接与边界 |
| 已同意但未完成最小认识 | ONB-001 第一次认识 |
| 已认识、今日未签到且未生成 | DLY-001 今日签到 |
| 今日结果正在生成 | DLY-002 生成状态 |
| 今日结果已生成 | DLY-003 今日内容 |
| 订阅消息指向晚间反馈且条件满足 | EVE-001 晚间反馈 |
| 分享深链且允许访问 | 对应公开承接，再进入自身今日路径 |
| 登录失效 | 静默恢复或 ENT-002 会话恢复状态 |
| 高风险固定流程触发 | SAFE-001 安全响应 |
| 服务维护或关键数据不可用 | SYS-004 维护与恢复 |

### 6.3 深链原则

- 深链只决定首次落点，不绕过身份、权限和数据边界；
- 失效深链回到今日入口；
- 分享卡片不能让接收者看到分享者的私人详情；
- 渠道参数只携带来源、素材和版本，不携带情绪或记忆；
- 订阅消息可以进入晚间反馈或今日内容，但不能制造坏运势紧迫感。

## 7. 小程序一级结构

MVP 不使用底部 TabBar，采用“今日页为根 + 次级入口”的结构。

### 7.1 今天

包含：

- 时段问候；
- 当天状态或签到入口；
- 今日整体能量；
- 今日重点维度；
- 可展开五维状态；
- 朋友式解释；
- 一个主要行动；
- 可选小任务；
- 点亮；
- 晚间反馈入口；
- 分享入口；
- 记录入口；
- 设置入口；
- 第 3、4、7 天关系卡片。

“今天”不是功能面板，不展示商城、角色列表、社区、排行榜和长内容流。

### 7.2 记录

包含：

- 最近 7 天真实趋势；
- 点亮情况；
- 晨间真实状态；
- 晚间反馈完成情况；
- 建议帮助度概览；
- 最近日记录列表；
- 第 7 天总结；
- 选中某日的历史详情。

MVP 不提供完整月历、月度预测、年度报告和复杂图表。

### 7.3 设置

包含：

- 资料与表达偏好；
- 重要事项；
- 提醒设置；
- 隐私与数据；
- 内容反馈与帮助；
- 产品说明和专业边界；
- 注销或结束关系数据。

设置不承载每日核心体验。

## 8. 新用户首次路径

### 8.1 推荐页面数量

渠道承接后，只使用两个业务页面完成首次核心输入：

1. ONB-001 第一次认识：称呼 + 表达偏好；
2. DLY-001 今日签到：情绪 + 精力 + 睡眠。

微信身份建立、必要同意和会话创建在承接页内完成，不增加独立“注册成功”页面。

### 8.2 流程

~~~mermaid
flowchart TD
    A["ENT-001 承接与边界"] --> B["必要同意与会话建立"]
    B --> C["ONB-001 称呼与表达偏好"]
    C --> D["DLY-001 情绪 / 精力 / 睡眠"]
    D --> E["DLY-002 生成状态"]
    E --> F["DLY-003 今日内容"]
    F --> G["点亮今天"]
~~~

### 8.3 返回规则

- 承接页退出：回到微信或渠道；
- 认识页退出：保存明确提交的选择，再次进入继续；
- 签到未提交退出：不保存半选状态，或只做本地草稿；
- 生成中退出：服务端继续或安全取消，再次进入读取唯一结果；
- 今日页退出：再次进入仍展示同一内容；
- 点亮后不自动跳转分享或通知授权。

## 9. 每日核心路径

### 9.1 未生成

> 启动 → 今日签到 → 生成状态 → 今日内容 → 点亮

签到完成后不提供“重新抽取”。如果用户发现输入错误，可修改资料供未来日期使用；当天核心结果默认不变。

### 9.2 已生成

> 启动 → 今日内容

今日页恢复：

- 阅读位置；
- 点亮状态；
- 小任务状态；
- 晚间反馈状态。

### 9.3 五维展示

推荐同页渐进展示：

- 首屏：整体能量 + 一个今日重点；
- 第二层：朋友式解释 + 主要行动；
- 展开区：其余五维状态和娱乐元素；
- 页面末端：点亮、反馈、分享。

不为五个维度创建五个独立详情页，避免增加认知和导航成本。

## 10. 晚间反馈

### 10.1 入口

- 今日页在合适时段显示“回看今天”卡片；
- 用户可主动从今日页进入；
- 用户授权后，订阅消息可以深链进入；
- 当天内容未生成时，不单独进入晚间反馈；
- 次日打开时，MVP 默认不强迫补填昨日反馈。

### 10.2 页面结构

EVE-001 为单页短流程：

- 今天整体感觉；
- 建议是否有帮助；
- 小任务是否完成；
- 可选一句话；
- 提交；
- 页面内简短收尾。

不创建独立“反馈成功”页，不在完成后发起长对话。

## 11. 记录与历史

### 11.1 推荐结构

REC-001 记录与七天趋势：

- 最近 7 天趋势；
- 点亮天数；
- 真实状态趋势；
- 数据缺失说明；
- 第 7 天总结；
- 最近日记录列表。

REC-002 历史日详情：

- 当日签到；
- 当日娱乐性今日能量；
- 当日行动；
- 点亮；
- 晚间真实反馈；
- 当时使用的内容版本说明入口。

### 11.2 暂不做完整月历

原因：

- MVP 首先验证连续 7 天；
- 用户记录不足时月历价值弱；
- 月历容易强化打卡和断签压力；
- 月度趋势需要更长数据窗口和新指标定义。

可以保留近期日记录列表，为未来月历留出信息结构，不在首版展示空月历。

## 12. 重要事项与记忆

### 12.1 获取入口

第 4 天可以在今日页出现可跳过卡片：

> 如果你愿意，可以记下一件近期在意的事。

用户点击后进入 MEM-002 新增重要事项。

### 12.2 长期管理

设置 → 重要事项 → MEM-001 列表 → MEM-002 新增或编辑。

重要事项页明确：

- 记录内容；
- 日期；
- 是否允许提醒；
- 是否允许在每日内容中提及；
- 状态和有效期；
- 修改和删除。

### 12.3 记忆范围

MVP 不提供“AI 记忆库”式复杂页面。用户能管理的是明确的结构化资料和重要事项。

短期签到、反馈和点亮通过记录页管理；长期记忆规范在 S-14 定义。

## 13. 设置、隐私与数据

### 13.1 设置入口

今日页顶部或页面末端提供低干扰设置入口。

SET-001 设置中心仅作为目录：

- 资料与表达偏好；
- 重要事项；
- 提醒；
- 隐私与数据；
- 帮助与反馈；
- 关于 DailyEnergy。

### 13.2 隐私分层

SET-004 隐私与数据独立页面，包含：

- 收集了什么；
- 数据用途；
- 主要资料查看；
- 记忆管理入口；
- 数据导出；
- 删除单日记录；
- 删除主要关系数据；
- 注销账户；
- 隐私说明和产品边界。

删除和注销使用明确确认，不使用诱导留存文案。

## 14. 分享

### 14.1 入口

- 今日内容页末端；
- 第 7 天总结区；
- 不在低分或敏感内容旁突出分享；
- 不在点亮完成后强制弹出。

### 14.2 预览

SHR-001 分享预览必须显示最终公开内容，默认隐藏：

- 称呼；
- 情绪、精力和睡眠原值；
- 晚间自由文本；
- 重要事项；
- 具体关系、工作、健康和财务内容；
- 记忆引用。

用户可以在有限模板中选择今日一句话、行动建议或七天点亮概览。

## 15. 通知与提醒

提醒设置位于 SET-003。

支持：

- 用户选择提醒类型；
- 选择允许的时段；
- 查看当前授权状态；
- 关闭提醒；
- 了解平台限制。

不在承接首屏、认识页和签到提交前请求通知授权。

提醒入口不与“坏运势”绑定。

## 16. 系统状态归属

### 16.1 加载

- 启动加载：SYS-001 启动路由骨架；
- 签到提交：DLY-001 按钮内状态；
- 新内容生成：DLY-002 独立生成状态；
- 今日页刷新：DLY-003 局部骨架；
- 趋势加载：REC-001 图表骨架；
- 数据导出：SET-004 任务状态。

### 16.2 空状态

- 无历史：REC-001 展示从今天开始；
- 无重要事项：MEM-001 提供解释和新增；
- 无提醒：SET-003 显示未开启；
- 无晚间反馈：历史日详情明确未记录；
- 数据不足：趋势不补造结论。

### 16.3 可恢复错误

优先在原页面内显示：

- 网络异常；
- 提交失败；
- 局部数据失败；
- 卡片生成失败；
- 授权拒绝。

提供重试、稍后继续或返回今天。

### 16.4 模板降级

- 在超时预算内自动切换模板时，不显示“AI 故障”等技术提示；
- 内容仍满足人格、安全和结构化事实时，用户完成正常旅程；
- 如果记忆或个性化暂时不可用，显示低干扰说明：“今天先用基础内容陪你完成这一分钟”；
- 记录降级事件供管理后台和分析使用；
- 降级后当天结果仍稳定。

### 16.5 不可恢复错误

使用 SYS-004：

- 维护；
- 关键账户状态异常；
- 今日结果无法读取且不能安全降级；
- 数据删除正在执行且相关功能不可用。

页面只提供安全重试、回到微信或联系支持。

### 16.6 高风险

SAFE-001 替代普通今日内容：

- 固定安全响应；
- 现实求助方向；
- 地区资源或紧急服务入口；
- 联系可信任的人；
- 返回普通流程的受控路径。

不显示运势、幸运元素、点亮、勋章和分享。

## 17. 最小管理后台信息架构

### 17.1 一级结构

推荐使用侧边导航：

- 运行概览；
- 内容与版本；
- 内容反馈；
- 安全事件；
- 用户支持；
- 指标与成本；
- 系统设置。

### 17.2 P0 能力

- ADM-002 运行概览；
- ADM-003 生成记录与脱敏详情；
- ADM-006 安全事件；
- ADM-007 用户支持和数据请求。

### 17.3 P1 能力

- Prompt、模型、规则和模板版本管理；
- 内容反馈聚合；
- 渠道和核心指标；
- Token、延迟和成本；
- 受控发布与回滚。

后台不允许：

- 修改用户真实签到或晚间反馈；
- 手工改变某用户当天分数；
- 绕过审计删除数据；
- 查看与任务无关的敏感原文；
- 为付费提高好运结果。

## 20. 导航和返回原则

- 今日是业务根页面；
- 记录、设置和重要事项使用次级页面；
- 从深链完成目标后返回今天，而不是进入未知页面；
- 返回操作不重复提交；
- 生成中返回不创建第二份结果；
- 删除确认返回数据管理页；
- 安全响应的返回由安全规范控制；
- 分享完成返回来源页面；
- 不用循环导航诱导停留；
- 不让用户通过返回绕过必要同意或账户状态。

## 22. 待审核决策

| 决策 | 推荐 | 理由 |
|---|---|---|
| 首页形态 | 动态今天页 | 减少一步，直达每日价值 |
| 首次认识 | 一个认识页 + 一个签到页 | 保持一分钟和渐进披露 |
